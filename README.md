# Web Technology - Experiment 1
### Aim
To design and develop a responsive multi-page website for TechFest 2026 using semantic HTML5 elements
and CSS3 (typography, box model, positioning, Flexbox, Grid and media queries).

### Question
A college is organizing its annual TechFest 2026 and requires a responsive website to provide event
information and collect registrations. Design and develop the website using HTML5 and CSS3.
1. Create a homepage with a suitable page title, logo, navigation menu, banner, welcome section, event
highlights, announcements, and footer.
2. Organize the webpage using appropriate semantic HTML elements.
3. Create separate sections to display Upcoming events, Event schedule, Organizing committee, and
Sponsors.
4. Display the event schedule in a tabular format.
5. Include suitable ordered, unordered, and description lists wherever appropriate.
6. Provide suitable hyperlinks for navigation within the site and to external pages.
7. Design an online registration form to collect participant details, ensuring appropriate HTML5
validation.
8. Embed images, audio, and a promotional video related to the event.
9. Apply CSS to create an attractive layout with suitable typography, colours, spacing, borders, hover
effects, and shadows.
10.Arrange different sections using Flexbox and Grid to ensure proper alignment and spacing.
11.Ensure that the website is fully responsive and displays correctly on desktop, tablet, and mobile
devices.
12.Organize all resources (HTML, CSS, images, media files) using an appropriate folder structure.

### Expected Output
• A five-page static website with consistent navigation and styling. <br>
• A schedule table and a registration form that blocks invalid input using HTML5 validation. <br>
• Layout adapting correctly at mobile, tablet and desktop widths without horizontal scrolling.
